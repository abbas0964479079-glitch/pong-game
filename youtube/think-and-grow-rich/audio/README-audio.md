## لماذا نسختان؟
الصوت الهادئ العميق يُقرأ ببطء طبيعي، فخرجت النسخة الخام في **17:03**. لتطابق المدة المستهدفة (8–12 دقيقة) تم تسريع النسخة النهائية إلى **1.40×** باستخدام `atempo` (يحافظ على حدة الصوت ولا يُحدث الصوت السريع المضحك)، فصارت **12:11**.

**الوقت المنقضي في `narration-12min.mp3` يطابق تقريبًا الأزمنة المكتوبة في `script.md`** (±15 ثانية)، لذا يمكنك بناء المونتاج على الفصول كما هي.

## أوامر مفيدة (ffmpeg)
> الأدوات هنا مستدعاة عبر `imageio_ffmpeg`. عندك محليًا استخدم `ffmpeg` العادي.

```bash
# إبطاء/تسريع بأي نسبة (1.30 = أبطأ وأهدأ | 1.45 = أسرع وأقرب إلى 11:46)
ffmpeg -i narration-raw-pace.mp3 -filter:a "atempo=1.45" -b:a 96k narration-11min.mp3

# إعادة دمج المقاطع الأصلية لو استبدلت أحدها
printf "file '%s'\n" narration-0{1,2,3,4,5,6,7}.mp3 > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy narration-full.mp3

# تطبيع مستوى الصوت لمعيار يوتيوب (−14 LUFS)
ffmpeg -i narration-12min.mp3 -filter:a loudnorm=I=-14:TP=-1.5:LRA=11 -b:a 192k narration-mastered.mp3
```

## ملاحظات مونتاج مهمة
1. **الفواصل التشويقية:** عند الجمل التي تبدأ بـ «لكن هنا توجد مشكلة…» / «والأخطر من ذلك…» / «وهذه النقطة تحديدًا يخطئ فيها معظم الناس…» / «لكن ماذا يحدث عندما تفشل الخطة؟» / «هنا نصل إلى واحدة من أهم أفكار الكتاب…» — **اخفض الموسيقى تمامًا قبلها بـ1.5 ثانية**، واترك الصوت وحده، ثم أعِد الموسيقى. هذا أقوى سلاح لإعادة الانتباه.
2. **الموسيقى:** −22 إلى −26 dB تحت التعليق، ومرشّح Low-pass خفيف (8kHz) حتى لا تزاحم تفاصيل الصوت.
3. **التطبيع:** شغّل `loudnorm` أعلاه قبل التصدير النهائي حتى لا تفقد القنوات الصوتية أمام فيديوهات منافسة أعلى صوتًا.
4. **لو أردت تسجيله بصوتك:** استخدم `voiceover-script.txt` كما هو — نفس النص ونفس الأزمنة المتوقعة عند 133 كلمة/دقيقة.
