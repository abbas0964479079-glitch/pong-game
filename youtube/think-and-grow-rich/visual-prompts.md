# 🎬 حزمة المشاهد البصرية (AI Prompt Pack)
### فيديو: «فكّر تصبح غنيًا» — مُلخّص الكتب

> **طريقة الاستخدام:** كل مشهد جاهز للنسخ. الصق **English Prompt** في أدوات الفيديو (Veo / Sora / Runway / Kling / Pika) أو في مولّد الصور (Midjourney / Imagen / Firefly) ثم حرّكها بحركة كاميرا بسيطة.
> **اللوك الموحّد (Style Suffix):** أضف هذه الجملة إلى نهاية كل برومبت:
> `cinematic, 35mm anamorphic lens, shallow depth of field, warm golden highlights with deep teal shadows, volumetric light, subtle film grain, photorealistic, 4K, 24fps`
> **Negative Prompt (لكل المشاهد):**
> `text, letters, arabic script, watermark, logo, distorted hands, extra fingers, deformed faces, cartoon, oversaturated, low quality, motion blur artifacts, celebrity likeness`

### 🎨 قواعد الاتساق (مهمة للاحتراف)
1. **بطل بصري واحد** يتكرر في 5 مشاهد: `a 30-year-old Middle Eastern man, short beard, simple dark jacket, carrying a small worn leather notebook`
2. **ثلاثة موتيفات** تتكرر: باب خشبي يتسلل منه ضوء ذهبي / دفتر جلدي مستهلك / خيط ذهبي رقيق.
3. **الحركة:** حركة كاميرا واحدة لكل مشهد (Slow Dolly In / Orbit / Crane Up). لا قطع داخلي.
4. **اللون:** كل مشهد «سعيد/تقدم» → ذهبي دافئ. كل مشهد «شك/تردد/فشل» → أزرق بارد خافت.
5. **مدة المشهد:** 6–9 ثوان ← ثم قطع ناعم أو Zoom Transition. لا تجعل لقطة واحدة تتجاوز 10 ثوان.

## 🛠️ ملاحظات إنتاج عملية

| البند | التوصية |
|---|---|
| **عدد المشاهد** | ~49 مشهدًا لـ11 دقيقة = متوسط 13 ثانية لمقطع الحركة. عمليًا ولّد 20–25 مشهدًا متحركًا واستخدم الباقي كصور ثابتة بتحريك Ken Burns/Parallax |
| **بديل اقتصادي** | توليد الصور الثابتة (Midjourney/Imagen) + تحريكها في المحرر (Zoom + Parallax + Grade) = نصف الوقت ونفس الجودة البصرية |
| **توليد مقاطع الفيديو** | ولّد 5 ثوان لكل مشهد ثم استخدم Slow Motion + Ramp للوصول إلى 8–9 ثوان |
| **الأشخاص الحقيقيون** | لا تستخدم صور شخصيات حقيقية (هيل، فورد، كروك). استخدم تمثيلًا سينمائيًا مجازيًا كما هو موصوف أعلاه |
| **الفصل بين المشاهد** | Zoom Transition / Light Leak / Luma Wipe — لا تستخدم Transitions مبتذلة (Cube, Spin) |
| **تشييك أخير** | تأكد أن كل مشهد يخدم الجملة التي تُقرأ فوقه. إن لم يخدمها، احذفه — المشهد الجميل بلا وظيفة يقتل الإيقاع |
