# 🎬 مجلد الفيديو

هذا المجلد يبني **الفيديو الكامل** من الصوت والصور والنصوص الموجودة في المشروع.

## 🎥 المخرجات (في `out/`)

| الملف | الوصف |
|---|---|
| `out/good-to-great-1080p.mp4` | **الفيديو الكامل** — 1920×1080، 30fps، 10:51، جاهز للرفع على يوتيوب |
| `out/thumbnail-15x.jpg` | ثامبنيل 1280×720 مستخرج من الفيديو |
| `out/thumbnail-1435.jpg` | ثامبنيل بديل |
| `out/thumbnail-outro.jpg` | ثامبنيل بديل |
| `out/audio.m4a` | المسار الصوتي النهائي (AAC) بعد إضافة الصمت بين المشاهد |

## 🧩 ما يحتويه الفيديو

- **الصور التسع** مع تقريب بطيء (Ken Burns) لمنع الإحساس بالثبات.
- **ترجمة عربية** أسفل الشاشة (مشكّلة بإعادة تشكيل الحروف العربية + bidi) مولّدة من ملفات `voiceover/scene-*.txt`.
- **بطاقات ذكية:** «المشهد 1 • الهوك» + التوقيت أعلى الشاشة.
- **لوحات أرقام متحركة:** `1$ → 15×`، `1435 → 11`، `−1,000,000$`، `+4,000,000$`، `25 سنة`.
- **كارت ختام** بدعوة للتفاعل (اشترك • اكتب: أبطّل إيه؟).
- **شريط تقدّم ذهبي** أسفل الشاشة يعكس موضع المشاهد.

## ▶️ إعادة البناء

```bash
cd video
python3 build_video.py            # الفيديو كامل + الثامبنيلات  (~12 دقيقة)
python3 build_video.py sample 300 # تجربة سريعة (10 ثوانٍ)
python3 build_video.py stills 6.5 130 420   # إطارات ثابتة للمعاينة
python3 build_video.py thumbs     # الثامبنيلات فقط
```

## ⚙️ المتطلبات

- `pillow`, `arabic-reshaper`, `python-bidi`, `numpy`, `imageio-ffmpeg` (تُثبَّت بـ pip)
- الخط العربي: `fonts/NotoSansArabic[wdth,wght].ttf` (مضمّن في المجلد)

## 📝 ملاحظات فنية

- **النص العربي في PIL:** لا يوجد دعم لتشكيل الحروف (Shaping) داخل Pillow، لذلك تُعالَج النصوص عبر `arabic_reshaper` + `python-bidi` قبل الرسم، مع خط Noto Sans Arabic الذي يحتوي على الأشكال المتصلة (`presentation forms`).
- **الخطوط:** الوزن يُضبط عبر `set_variation_by_axes([Weight, Width])` لأن الخط متغيّر (Variable Font).
- **الأداء:** الخلفيات تُدمج مع طبقات التعتيم مرة كل 4 إطارات (10Hz) — التقريب بطيء جدًا فالإحساس سلس، والزمن النهائي ~12 دقيقة لكل 11 دقيقة فيديو.
- **التوقيتات:** تُقرأ من مدد مقاطع الصوت الحقيقية، فلا يوجد أي انزياح بين الكلام والترجمة.
